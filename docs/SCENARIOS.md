# 마이링크 사용자 시나리오

## 1. 방문자 시나리오
*   사용자는 소유자의 다양한 소셜 미디어와 콘텐츠를 한곳에서 확인하기 위해 **공유된 마이링크 고유 URL(@displayName)로 접속한다.**
*   사용자는 원하는 콘텐츠로 이동하기 위해 **나열된 링크 버튼 중 하나를 클릭한다.**
*   사용자는 모바일 환경에서도 쾌적하게 링크를 확인하기 위해 **반응형으로 최적화된 마이링크 페이지를 이용한다.**

## 2. 소유자 시나리오
*   사용자는 자신의 링크 페이지를 관리하기 위해 **Google 계정으로 로그인하여 관리자 대시보드에 진입한다.**
*   사용자는 새로운 연결 통로를 추가하기 위해 **링크 추가 버튼을 누르고 URL과 제목을 입력한다.**
*   사용자는 잘못 입력된 정보를 바로잡기 위해 **수정하고 싶은 텍스트를 클릭하여 인라인으로 즉시 편집한다.**
*   사용자는 더 이상 필요 없는 링크를 제거하기 위해 **삭제 버튼을 눌러 리스트에서 제외한다.**
*   사용자는 중요한 링크를 상단에 배치하기 위해 **드래그 앤 드롭 기능을 사용하여 링크의 순서를 변경한다.**
*   사용자는 페이지의 분위기를 바꾸기 위해 **제공되는 테마 중 하나를 선택하여 전체 디자인을 적용한다.**
